# Chaft brand assets

These files are the original raster exports supplied in `Chaft Brand assets`.
They are intentionally kept unmodified so the desktop application can use the
approved mark and wordmark directly.

Runtime use:

- `chaft-mark.png`: transparent primary mark and application icon.
- `../macos/Chaft.icns`: macOS application icon generated from the primary
  mark, with native icon representations from 16 through 1024 pixels.
- `chaft-wordmark.png`: transparent horizontal wordmark for light surfaces.
- `chaft-avatar-light.png` and `chaft-avatar-dark.png`: square presentation
  variants for light and dark contexts.
- `chaft-mark-frame.png` and `chaft-mark-frame-horizontal.png`: frame-only
  exports retained for future composition.

The primary logo anchors used by the default themes are:

- Ink: `#222426`
- Night: `#182021`
- Blue: `#2F54A5`
- Sky: `#66BEEB`
- Coral: `#F48058`
- Violet: `#414287`

The gradient remains confined to the logo. Product surfaces use these anchors
as solid semantic colors so text contrast, hierarchy, and state meaning remain
predictable.
